Cara mendapatkan Kunci VAPID?

1. Masuk ke Firebase Console, pilih proyek smagesa.

2. Klik ⚙️ (Gear) -> Project settings -> tab Cloud Messaging.

3. Scroll ke bawah ke area Web configuration.

4. Klik Generate Key Pair pada Web Push certificates.

5. Salin kode panjang tersebut ke kolom di atas.
